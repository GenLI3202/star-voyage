# 星空远征 · star-voyage

[English](README.md)

Claude 桌面端的一套皮肤（mod）：一艘飞往你自己定下的那一天的飞船。可以是毕业、上线、一场比赛，或者随便哪个值得倒数的日子。

- **巡航**：一张星图，飞船停在航线的当前进度上，行星沿轨道缓缓转动。每次回到巡航，侧栏显示十秒航程进度，然后随风散去。
- **打字**：停顿下来的那一刻，镜头按草稿长度分三档靠近飞船，尾焰变亮。
- **发送**：镜头扎进飞船，切到第一人称的星际穿梭，侧栏立起一根竖直的航程轴；回合结束时拉回星图，浮现一句诗。
- **新对话**：还没发过消息的对话停在港湾里；第一条消息发出时，脚下的星球沉下去，飞船离港。
- **入港**：闲置到提示缓存变凉（默认 60 分钟）后，飞船停在一颗小星球的地平线上，头顶是银河。打字即离港。
- **诗句**：龙藏体竖排，自右向左，出处小字落在左下，像落款。五十多句古诗词，大多与星河、远行有关。
- **小队**：同时开着的其他对话，是在别的星系干活的小队：一颗小星、一圈轨道、一盏灯、一个名字。
- **昼夜**：夜间是深空配色；日间是 Claude 自己的暖纸色，星图改用墨线。跟着系统的明暗自动切换。
- **两个音**：出发一个，抵达一个。
- **省着用**：默认只在有事发生时播放动画，默认不用 App 的毛玻璃面板。两样都是量过之后定的，见"内存"一节。

## 安装

在终端里的 Claude Code 会话中输入：

```text
/plugin install star-voyage --marketplace GenLI3202/star-voyage
```

问到 `Add marketplace?` 时回答 `y`，再选安装范围（用户范围排在第一个，回车即可）。

或者在命令行里：

```bash
claude plugin install star-voyage --marketplace GenLI3202/star-voyage
```

在桌面 App 里（`/plugin` 在那里不能用）：点输入框旁边的 **+**，选 **Plugins**，**Add marketplace** 填 `GenLI3202/star-voyage`，再 **Add plugin**。

装好之后，开着的对话闲下来就会换上皮肤。`/voyage off` 随时关掉，回到 App 自己的样子。

## 设定你的航程

刚装上时，航程从安装那天开始，一年后抵达，沿途没有港湾。用命令改成你自己的：

```text
/voyage from 2024-09-01          启航日
/voyage to 2028-06-30 毕业        抵达日，和它叫什么（用在"距毕业还有 N 天"）
/voyage port 2025-06-01 开题      在航线上加一个港湾
/voyage port 2026-09-01 中期
/voyage port remove 中期          去掉一个港湾
/voyage port clear               去掉全部港湾
/voyage from reset               启航日改回安装那天
/voyage to reset                 抵达日改回一年后
```

日期写成 `YYYY-MM-DD`。终点名最多 6 个字，港湾最多 8 个、每个名字最多 8 个字；落在启航和抵达之间的港湾才会画出来。航程和其他设置一样，所有对话共用：在一个对话里改了，其他开着的对话十秒内跟上。直接输入 `/voyage` 可以看到现在的航程。

## 其他命令

- `/voyage`：查看状态（航程、看到了哪些小队、本对话被上报成什么）。
- `/voyage dock`：立刻入港；`/voyage poem`：来一句诗。
- `/voyage motion low|full|calm|still`：动效。`low` 每秒重画几次；`full` 顺滑；`calm`（默认）有事才动：穿梭开头、抵达、离港、诗句出现和散去时动，其余时间是一幅静止的画；`still` 完全不动。
- `/voyage ground <像素>`：画面底部让给输入区的高度，见下面"地面"一节。默认 120。
- `/voyage glass off`（默认）或 `/voyage glass <模糊 0–64> <遮罩 0–1>`：App 的毛玻璃面板。打开后侧边栏和卡片会透出背景，代价见"内存"一节。`/voyage veil <0–0.8>` 调画面自带遮罩的深浅。
- `/voyage side <偏移>`：左右挪侧栏（-10 到 200）。侧栏默认紧贴正文右边，正数往外挪。
- `/voyage fleet on|off`：小队；`/voyage warm <分钟>`：一个对话在最后一次活动后多久还算在外的小队。
- `/voyage cool <分钟>`：闲置多久入港；`/voyage sound on|off`：音效。
- `/voyage off` / `/voyage on`：关掉 / 打开皮肤。

## 侧栏

背景铺满整个窗口，对话的文字会压在它上面。所以细字都排在对话栏右边：诗句紧贴正文，出处在诗句正下方，再往右一条小字（穿梭时是航程轴，抵达时是进度，入港时是一句问候）。紧贴正文是为了右侧面板打开时尽量不被挡住。小队在对话栏左边。皮肤不知道侧边栏和面板开没开：左侧会话栏打开时正文会往右让，诗句可能压到正文上，这时用 `/voyage side 90` 往外挪，收起后 `/voyage side 0` 挪回来。

## 地面：输入区后面那块底板

毛玻璃关着时，App 会在输入区后面垫一块不透明的底板，颜色是页面底色，从输入区上沿一直到窗口底边。输入区越高（上面有卡片、贴了图、打了好几行字），底板越高。皮肤既不知道它在，也不知道它多高；底板压在星球或光晕上，就像一个切掉画面的黑框。

所以画面把窗口底部的一段画成同样的颜色，底板落在上面就看不出来。默认 120 像素，大约盖住一行输入框和状态栏。输入区比它高时会露出一截底板；常常贴图或有卡片的话，调到 250–380。`/voyage ground 0` 不留地面。毛玻璃打开时没有底板，这个设置不起作用。

## 小队

- 灯的颜色：**绿**，正在干活（灯会呼吸）；**蓝**，等你回话；**暗蓝**，闲置入港；**红**，在叫你（提问、等你批计划、权限请求，或上一轮出错中断）。
- 名字取对话的标题，标题还没生成时取开头的一句话，再没有就取文件夹名。
- 发过消息的对话才算小队；从最后一次活动算起 60 分钟内（提示缓存还热）都会显示，凉了就消失。
- 小队排在对话栏左边那片空白的正中，离窗口左缘和离正文左缘一样远。皮肤不知道左侧边栏开没开，开着侧边栏时小队会被盖住。
- 对话之间靠一个文件夹传话：`~/.claude/star-voyage/fleet/`，每个对话一个小文件（对话 id、显示名、状态、最近一次活动的时间）。文件只在这台机器上，一天没动的会被清掉，不会发到任何地方。`/voyage fleet off` 让这个对话既不显示别人，也不上报自己。

## 改诗句

诗句在 `hooks/poems.ts`。诗句用龙藏体书写，字形轮廓随皮肤一起带着（`hooks/glyphs.ts`）。加了新句子后，新用到的字需要重新生成字形，否则那些字会退回系统行楷。在皮肤文件夹里运行：

```bash
uv run --no-project --with fonttools python3 -I tools/glyphs.py tools/LongCang-Regular.ttf hooks/poems.ts hooks/glyphs.ts
```

## 内存

在一个 5K 窗口上读 App 图形进程的内存，逐项拆开量过（上下浮动约 0.1 GB）：

| 状态 | 图形进程 |
| --- | --- |
| 皮肤关闭 | 约 1.0 GB |
| 背景静止，毛玻璃关 | 约 1.05–1.2 GB |
| 背景在播动画，毛玻璃关 | 港湾约 1.2 GB，穿梭约 1.6 GB |
| 背景静止，毛玻璃开 | 约 1.65–1.8 GB |

- **贵的是毛玻璃，不是画。** 毛玻璃打开时，一幅空白背景就比关掉皮肤多占约 0.5 GB。而且没有便宜档：模糊 0、完全透明，也是整份开销。所以默认关。
- **静止的画几乎不花钱，动画只在播放时花钱。** 所以默认"有事才动"。
- **只有正在看的那个对话在画背景**，开着的对话再多也只算一份。

想要更华丽的样子：`/voyage glass 0 0.2` 加 `/voyage motion low`。

`/voyage lab <开关>` 可以把画面拆开来量：`scene=cruise|dock|work|verse|workverse|jump` 固定画某个场景，`motion=…` 临时改动效，`bare` 画空白，`colors` 只换配色，`noglass`、`nostars`、`noglow`、`noside`、`nosquads`、`flat` 去掉画面的一部分；`/voyage lab off` 关闭。

**点开一个旧对话却完全没有背景**，多半不是皮肤的事：App 限制同时运行的后台进程数（内存 ÷ 3 GB，最少 6），超了就不给只是"点开看看"的对话启动进程，这时所有 mod 都不加载。发一条消息就回来了。

## 桌面端怎么画它（改场景前必读）

1. **App 先画一张去掉全部动画的静止版。** 所以每个图层自己的样式必须就是它最终的样子，动画只负责"怎么进场"。
2. **只有通过严格检查的 SVG 才会动**，通过后被当作一张图播放。检查只允许按明暗和"减少动效"写 `@media`，只允许一小张名单里的 CSS 函数，不许出现 `vector-effect`、`shape-rendering`、视口单位、`data:`，`url()` 只能是 `url(#id)`，背景必须是单独一个 SVG。播放时它还会逐帧计时并监测闪烁，太贵或太闪就停回静止版。`tests/voyage.test.tsx` 逐个状态检查这些规矩。
3. **毛玻璃关着时输入区后面有底板**（`data-docked-column-backing`）。要避开它的东西都画在一张"挂在窗口底边"的子图里（`<svg y="100%" style="overflow:visible">`，一个单位就是一个像素，往上是负的 y）。

小队的名字是别人起的标题，一个不合规矩的字符就会让整张背景停回静止版，所以进画面之前只留字母、数字和几个朴素的标点。

App 的"背景动画"外观设置关闭、系统开启"减少动态效果"、或没有显卡加速时，一律只画静止版。
